In 2015, Joseph Redmon, Santosh Divvala, Ross Girshick, and Ali Farhadi introduced a novel algorithm for object detection. 

They named it YOLO — You Only Look Once — for a specific reason. Earlier object detection models, like the R-CNN series, were also performing both classification and localization, but not in a single step: they relied on multiple stages (proposing candidate regions, classifying them, then refining the boxes) and multiple passes over the image. 

YOLO collapsed all of that into a single stage — one pass over the image to do both classification and localization at once.

## The Building Block: One Neuron

The fundamental unit is the **artificial neuron** (sometimes called a perceptron). Given an input vector $\mathbf{x} = [x_1, x_2, \ldots, x_n]$, a single neuron computes:

$$z = \mathbf{w}^T \mathbf{x} + b = \sum_{i=1}^{n} w_i x_i + b$$

$$a = \sigma(z)$$

Where:
- $\mathbf{w}$ is a **weight vector** (what the neuron "pays attention to")
- $b$ is a **bias** (shifts the activation threshold)
- $\sigma$ is an **activation function** (introduces non-linearity)

Without the activation function $\sigma$, stacking multiple layers would be pointless — the composition of linear functions is still linear. The activation function is what gives neural networks their expressive power.

## Common Activation Functions

**ReLU** (Rectified Linear Unit) is the modern workhorse:

$$\text{ReLU}(z) = \max(0, z)$$

It's dead simple — output the input if positive, else zero. Yet it works remarkably well. Why? It avoids the **vanishing gradient problem** that plagued older functions like sigmoid.

**Sigmoid** squashes inputs to $(0, 1)$:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Useful for output layers in binary classification, but problematic in deep hidden layers — gradients shrink toward zero far from the origin.

**Tanh** is a scaled sigmoid, outputting $(-1, 1)$:

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

## From Neurons to Layers

A **layer** is just a collection of neurons that all take the same input. If layer $l$ has $m$ neurons and receives an input of dimension $n$, we can write the whole layer as a matrix operation:

$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$$

$$\mathbf{a}^{(l)} = \sigma\left(\mathbf{z}^{(l)}\right)$$

Where $\mathbf{W}^{(l)}$ is an $m \times n$ weight matrix. This is just a linear transformation followed by an element-wise non-linearity.

## Why Deep?

The "deep" in deep learning refers to having many layers. Why does depth help?

Each layer learns to represent the input in terms of increasingly abstract features. In an image classifier:
- Early layers detect edges and textures
- Middle layers detect shapes and parts
- Later layers detect objects and concepts

This **hierarchical feature learning** is what makes deep networks so powerful — they don't need hand-crafted features.

## A Minimal Implementation

Here's a two-layer neural network in pure NumPy:

```python
import numpy as np

def relu(z):
    return np.maximum(0, z)

def forward(X, W1, b1, W2, b2):
    # Hidden layer
    z1 = X @ W1.T + b1      # (batch, hidden)
    a1 = relu(z1)
    
    # Output layer
    z2 = a1 @ W2.T + b2     # (batch, output)
    return z2

# Random init
np.random.seed(42)
W1 = np.random.randn(64, 784) * 0.01   # hidden_size x input_size
b1 = np.zeros(64)
W2 = np.random.randn(10, 64) * 0.01    # output_size x hidden_size
b2 = np.zeros(10)

# One forward pass (batch of 32, 784-dim input like flattened MNIST)
X = np.random.randn(32, 784)
output = forward(X, W1, b1, W2, b2)
print(output.shape)  # (32, 10)
```

## The Key Insight

A neural network is a parameterized function. The **weights** $\mathbf{W}$ and **biases** $\mathbf{b}$ across all layers are the parameters. Training is the process of finding parameter values such that the function does what we want on our data.

*How* we find those values — that's gradient descent and backpropagation, which we'll cover next.
