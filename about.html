About this blog

Neural Notes

A deep learning blog · Built with Jekyll & GitHub Pages

Welcome to Neural Notes — a blog about understanding deep learning from the ground up. The goal here is to write clear, mathematically honest explanations of the concepts that power modern AI.

What you'll find here

Posts cover the fundamentals — backpropagation, gradient descent, convolutional networks, attention mechanisms — as well as implementation in Python and PyTorch. Every post tries to build intuition before diving into formulas.

How this site is built

This blog is built with Jekyll and hosted for free on GitHub Pages. Math is rendered using KaTeX. Source code is available on GitHub.

Topics covered

  • Neural network fundamentals (perceptrons, activations, layers)
  • Backpropagation and automatic differentiation
  • Optimization: SGD, Adam, learning rate schedules
  • Convolutional Neural Networks (CNNs)
  • Recurrent networks and LSTMs
  • Transformers and attention mechanisms
  • Regularization: dropout, batch norm, weight decay
  • Practical PyTorch implementations
